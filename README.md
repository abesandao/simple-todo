# シンプルToDo（PWA）

日本語で書くだけで日付・時刻・繰り返しが付く、シンプルなToDoアプリ。

## 起動（PC）
```
python -m http.server 8765
```
→ http://localhost:8765 を開く

## スマホで使う
PWAは **HTTPS** で配信する必要があります（localhost以外）。GitHub Pages / Netlify / Cloudflare Pages などにこのフォルダをそのまま置けばOK。
- iPhone: Safariで開く → 共有 → 「ホーム画面に追加」
- Android: Chromeで開く → メニュー → 「アプリをインストール」

## 使い方
- クラフト紙のメモ帳風の画面。上が **Important Task**（重要）、下が **ToDo List**、一番下が **Memo**
- 空いている行をタップするとその行に直接書けます（Enterで次の行へ）
- 完了: □ をタップ、または行を **左→右になぞる** と横線が引かれます。右→左になぞると元に戻せます
- 行の文字をタップすると編集（重要の切り替え・日付・時刻・繰り返し・リスト・削除）
- 「済みを消す」で横線を引いたタスクを片付けられます

## 入力の例
| 入力 | 結果 |
|---|---|
| 明日15時に歯医者 | 明日 15:00 |
| 金曜までにレポート | 次の金曜 |
| 来週の水曜日 打ち合わせ | 来週水曜 |
| 12月25日 / 1/5 / 20日 | その日付 |
| 3日後 / 2週間後 | n日後 |
| 夜 電話 / 午後3時半 | 20:00 / 15:30 |
| 毎日・毎朝・毎晩・平日・毎週月曜・毎月25日・毎年 | 繰り返し |
| 資料作成 #仕事 | 「仕事」リストへ（なければ作成） |
| !企画書 / 重要 企画書 | Important Task に入る |

## 構成
- `index.html` / `styles.css` / `app.js` — 画面とロジック（データは端末の localStorage に保存）
- `parser.js` — 日本語の自然言語パーサー（テスト: `node tests/parser.test.js`）
- `sw.js` — オフライン対応・通知タップ処理
- `manifest.webmanifest`, `icons/` — ホーム画面アプリ用

## 制約
- 通知はアプリが開いている／バックグラウンドに残っている間だけ鳴ります。完全に閉じていても鳴らすにはプッシュ通知サーバーが必要です。
- iPhoneの通知は「ホーム画面に追加」したアプリでのみ使えます（iOS 16.4以降）。
- データは端末内のみ。機種変更・複数端末の同期は未対応です。
